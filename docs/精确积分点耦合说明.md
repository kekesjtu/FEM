## 求解流程对比

### 原始流程
```
迭代 n:
  1. 计算 T_avg = mean(T^(n-1))
  2. 设置 σ = σ0[1 + α(T_avg - T0)]  ← 使用平均值
  3. 组装 K_electric（使用常数σ）
  4. 求解电场 → V^n
  5. 求解热场 → T^n
```

### 改进流程（完整版）
```
迭代 n:
  1. [电场] 对每个单元e，每个积分点gp:
     T_gp = interpolate(T^(n-1), e, gp)     ← 插值温度
     σ_gp = σ0[1 + α(T_gp - T0)]           ← 积分点电导率
  2. 组装 K_electric（考虑σ空间变化）
  3. 求解电场 → V^n
  
  4. [热场] 对每个单元e，每个积分点gp:
     T_gp = interpolate(T^(n-1), e, gp)     ← 插值温度
     Q_gp = σ_gp * |∇V^n|²_gp              ← 积分点焦耳热
  5. 组装 b_thermal（精确焦耳热源）
  6. 求解热场 → T^n
```
