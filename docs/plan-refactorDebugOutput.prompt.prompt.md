# Plan: 整理调试信息输出

当前程序的调试输出非常杂乱,包含大量重复信息、格式不统一的分隔线以及冗余的中间过程输出。需要建立统一的输出层级控制系统,提高输出的可读性和专业性。

## Steps

1. **创建统一的日志输出工具类** 在 `include/logger.h` 和 `src/core/logger.cpp` 中实现分级日志系统(ERROR, WARNING, INFO, DEBUG),支持通过枚举控制输出详细程度,替代散落在各处的 `std::cout` 和 `std::cerr`

2. **重构 `electrothermal_solver.cpp` 的输出** 将构造函数中的初始化信息调整为 INFO 级别,迭代过程中的详细信息改为 DEBUG 级别,仅在 DEBUG 模式下输出每次迭代的积分点插值和矩阵组装信息,收敛信息保持为 INFO 级别

3. **重构 `fem_solver.cpp` 的输出** 简化组装和边界条件处理的输出,将矩阵三元组数量、非零元素统计等改为 DEBUG 级别,CG 求解器的迭代次数和误差保持为 INFO 级别,移除冗余的"步骤 X 完成"输出

4. **重构 `comsol_mesh_importer.cpp` 的输出** 将详细的解析过程(如"找到单元类型"、"成功读取 X 个几何实体索引")改为 DEBUG 级别,仅保留关键的网格导入统计信息(节点数、单元数)为 INFO 级别,错误信息保持为 ERROR 级别

5. **统一分隔线和格式** 将所有 `====` 和 `---` 分隔线统一为两种标准格式(主标题使用 50 字符宽的双线,次级标题使用单线),在 `main.cpp` 中调整整体输出结构,使程序启动、求解过程、结果输出三个阶段层次清晰

6. **在 `Config` 类中添加日志级别配置** 在 `include/config.h` 和 `src/core/config.cpp` 中添加日志级别设置,支持从 JSON 配置文件读取日志级别(如 `"log_level": "INFO"`),并通过构造函数参数传递给各求解器
