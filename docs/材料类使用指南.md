# 材料类使用指南（简化版）

## 概述

材料系数类 (`MaterialCoefficient`) 用于管理不同几何域的材料系数函数：
- 支持最多 **5个几何域**
- 每个域可以设置常数、空间依赖或温度依赖的系数
- 通过域编号（0-4）直接访问，无需复杂的映射

单元域映射类 (`ElementDomainMap`) 用于管理单元到域的映射关系。

## 基本使用

### 1. 创建材料系数对象

```cpp
#include "material.h"

// 创建材料系数对象，默认值为1.0
MaterialCoefficient thermal_conductivity(1.0);
MaterialCoefficient electrical_conductivity(1.0);
```

### 2. 为不同域设置系数

#### 设置常数系数
```cpp
// 域0: 铜导体，热导率 400 W/(m·K)
thermal_conductivity.setDomainCoefficient(0, 400.0);

// 域1: 铝导体，热导率 237 W/(m·K)
thermal_conductivity.setDomainCoefficient(1, 237.0);

// 域2: 空气，热导率 0.026 W/(m·K)
thermal_conductivity.setDomainCoefficient(2, 0.026);
```

#### 设置空间依赖系数
```cpp
// 域0: 热导率随位置变化
thermal_conductivity.setDomainCoefficient(
    0,
    [](const std::vector<double>& coords) -> double {
        double x = coords[0];
        double y = coords[1];
        return 400.0 + 50.0 * x;  // k = 400 + 50x
    }
);
```

#### 设置温度依赖系数（用于非线性问题）
```cpp
// 域0: 电导率随温度变化（电热耦合）
double sigma0 = 5.96e7;  // S/m，参考电导率
double alpha = 0.00393;  // 1/K，温度系数
double T0 = 300.0;       // K，参考温度

electrical_conductivity.setDomainCoefficientTemperatureDependent(
    0,
    [sigma0, alpha, T0](const std::vector<double>&, double T) -> double {
        return sigma0 / (1.0 + alpha * (T - T0));
    }
);
```

### 3. 获取系数值

```cpp
std::vector<double> coords = {x, y, z};

// 获取域0在指定位置的热导率
double k = thermal_conductivity.getCoefficient(0, coords);

// 获取域0在指定位置和温度的电导率
double sigma = electrical_conductivity.getCoefficient(0, coords, temperature);

// 检查是否依赖温度
bool temp_dep = electrical_conductivity.isTemperatureDependent(0);
```

### 4. 设置单元-域映射

```cpp
// 创建单元-域映射
ElementDomainMap domain_map;

// 方式1: 手动设置映射
std::vector<int> element_to_domain(num_elements);
for (int e = 0; e < num_elements; ++e) {
    if (/* 单元e属于铜导体区域 */) {
        element_to_domain[e] = 0;  // 域0
    } else if (/* 单元e属于铝导体区域 */) {
        element_to_domain[e] = 1;  // 域1
    } else {
        element_to_domain[e] = 2;  // 域2（空气）
    }
}
domain_map.setMapping(element_to_domain);

// 方式2: 所有单元属于同一个域（简化情况）
domain_map.setUniformDomain(num_elements, 0);  // 所有单元属于域0

// 获取单元所属的域
int domain_id = domain_map.getDomain(element_id);

// 获取该单元的热导率
double k_element = thermal_conductivity.getCoefficient(domain_id, coords);
```

## 完整示例：多域热传导问题

```cpp
#include "material.h"

// 1. 创建热导率系数对象
MaterialCoefficient thermal_k(1.0);  // 默认值1.0

// 2. 设置各个域的热导率
thermal_k.setDomainCoefficient(0, 400.0);   // 域0: 铜
thermal_k.setDomainCoefficient(1, 237.0);   // 域1: 铝
thermal_k.setDomainCoefficient(2, 0.026);   // 域2: 空气

// 3. 创建单元-域映射
ElementDomainMap domain_map;
std::vector<int> element_to_domain = {
    0, 0, 0, 0, 0,  // 前5个单元属于域0（铜）
    1, 1, 1,         // 接下来3个属于域1（铝）
    2, 2             // 最后2个属于域2（空气）
};
domain_map.setMapping(element_to_domain);

// 4. 在求解器中使用
for (int e = 0; e < num_elements; ++e) {
    int domain_id = domain_map.getDomain(e);
    
    // 在积分点处获取热导率
    std::vector<double> coords = {x_gauss, y_gauss, z_gauss};
    double k = thermal_k.getCoefficient(domain_id, coords);
    
    // 使用k进行刚度矩阵组装...
}
```

## 集成到求解器

### 在 FEMSolver 中添加材料支持

```cpp
class FEMSolver {
private:
    std::shared_ptr<MaterialCoefficient> coefficient_;
    std::shared_ptr<ElementDomainMap> domain_map_;
    
public:
    void setMaterialCoefficient(std::shared_ptr<MaterialCoefficient> coef) {
        coefficient_ = coef;
    }
    
    void setDomainMap(std::shared_ptr<ElementDomainMap> map) {
        domain_map_ = map;
    }
    
    // 修改刚度矩阵计算
    double calculateStiffnessEntry(int e, int alpha, int beta) {
        // 获取单元e所属的域
        int domain_id = domain_map_->getDomain(e);
        
        // 在积分点处获取材料系数
        std::vector<double> coords = {x_gauss, y_gauss, z_gauss};
        double c = coefficient_->getCoefficient(domain_id, coords);
        
        // 继续计算...
    }
};
```

### 在电热耦合求解器中使用

```cpp
class ElectrothermalSolver {
private:
    std::shared_ptr<MaterialCoefficient> thermal_k_;
    std::shared_ptr<MaterialCoefficient> electrical_sigma_;
    std::shared_ptr<ElementDomainMap> domain_map_;
    
    double getThermalConductivity(int element_id, const std::vector<double>& coords) {
        int domain_id = domain_map_->getDomain(element_id);
        return thermal_k_->getCoefficient(domain_id, coords);
    }
    
    double getElectricalConductivity(int element_id, const std::vector<double>& coords, 
                                     double temperature) {
        int domain_id = domain_map_->getDomain(element_id);
        return electrical_sigma_->getCoefficient(domain_id, coords, temperature);
    }
};
```

## 注意事项

1. **域编号范围**：域编号必须在 [0, 4] 范围内（最多5个域）
2. **未设置的域**：如果访问未设置的域，将返回默认值
3. **优先级**：温度依赖 > 空间依赖 > 常数
4. **单元-域映射**：必须在使用前设置映射关系
5. **扩展性**：如果需要超过5个域，修改 `MaterialCoefficient::MAX_DOMAINS` 常量
