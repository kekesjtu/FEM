# 电热耦合算例说明

## 1. 物理问题描述

本算例实现了双向电热耦合仿真，求解以下耦合方程组：

### 1.1 控制方程

**电场方程（稳态）**：
```
-∇·(σ(T)∇V) = 0
```

**热场方程（稳态）**：
```
-∇·(k∇T) = Q(V,T)
```

其中：
- `V`：电势 [V]
- `T`：温度 [K]
- `σ(T) = σ0[1 + α(T-T0)]`：温度依赖的电导率 [S/m]
- `k`：热导率（常数）[W/(m·K)]
- `Q(V,T) = σ(T)|∇V|²`：焦耳热密度 [W/m³]

### 1.2 耦合机制

- **电→热**：电场产生的焦耳热 `Q = σ(T)|∇V|²` 作为热场的源项
- **热→电**：温度影响电导率 `σ(T)`，进而影响电场分布

## 2. 算例配置

### 2.1 几何

- **域**：单位圆 (x² + y² ≤ 1)
- **网格**：从COMSOL导入的三角形网格（`circle_mesh2.mphtxt`）

### 2.2 物理参数

```cpp
sigma0 = 1.0      // 参考电导率 [S/m]
alpha  = 0.003    // 温度系数 [1/K]
k      = 1.0      // 热导率 [W/(m·K)]
T0     = 300.0    // 参考温度 [K]
```

### 2.3 边界条件

#### 电场边界条件

建议配置（需在 `Config::initializeBoundarys()` 中实现）：

- **左半圆** (x < 0)：Dirichlet条件 `V = 1.0 V`
- **右半圆** (x > 0)：Dirichlet条件 `V = 0.0 V`

或：
- **上半圆** (y > 0)：Dirichlet条件 `V = 1.0 V`
- **下半圆** (y < 0)：Dirichlet条件 `V = 0.0 V`

#### 热场边界条件

- **整个边界**：Robin条件（对流换热）
  ```
  -k ∂T/∂n = h(T - T_amb)
  ```
  其中：
  - `h = 10 W/(m²·K)`：对流换热系数
  - `T_amb = 300 K`：环境温度

## 3. 求解算法

采用**固定点迭代法**求解耦合问题：

```
初始化: T^0 = T0 (环境温度)

for iter = 1 to max_iter:
    1. 计算电导率: σ^iter = σ0[1 + α(T^(iter-1) - T0)]
    2. 求解电场: -∇·(σ^iter ∇V) = 0  →  V^iter
    3. 计算焦耳热: Q^iter = σ^iter |∇V^iter|²
    4. 求解热场: -∇·(k∇T) = Q^iter  →  T^iter
    5. 检查收敛: ||T^iter - T^(iter-1)||/||T^iter|| < tol
```

## 4. 代码使用

### 4.1 基本用法

在 `main.cpp` 中：

```cpp
#include "electrothermal_solver.h"

int main() {
    // 创建配置对象（需配置边界条件）
    auto config_electric = std::make_shared<Config>();
    auto config_thermal = std::make_shared<Config>();

    // 物理参数
    double sigma0 = 1.0, alpha = 0.003, k = 1.0, T0 = 300.0;

    // 创建求解器
    ElectrothermalSolver solver(config_electric, config_thermal,
                                 sigma0, alpha, k, T0,
                                 1e-6,  // 收敛容差
                                 50,    // 最大迭代次数
                                 true); // 详细输出

    // 求解
    solver.solve();

    // 输出结果
    solver.outputResults("results/electrothermal");

    return 0;
}
```

### 4.2 配置边界条件

需要修改 `src/config.cpp` 中的 `Config::initializeBoundarys()` 函数，根据节点位置设置不同的边界条件：

```cpp
void Config::initializeBoundarys(const std::vector<std::vector<int>>& edge_elements)
{
    boundarys.clear();
    boundarys.reserve(edge_elements.size());

    for (const auto& edge : edge_elements)
    {
        Boundary boundary;

        // 获取边界节点坐标
        double x0 = node_coordinates_[edge[0] * dimension_ + 0];
        double x1 = node_coordinates_[edge[1] * dimension_ + 0];
        double x_center = (x0 + x1) / 2.0;

        // 根据位置设置不同边界条件
        if (x_center < 0)
        {
            // 左半圆: V = 1.0 V (Dirichlet)
            boundary.bc = BoundaryCondition::Dirichlet(1.0);
        }
        else
        {
            // 右半圆: V = 0.0 V (Dirichlet)
            boundary.bc = BoundaryCondition::Dirichlet(0.0);
        }

        boundary.element_index = findElementContainingEdge(edge);
        boundary.global_node_indices_in_element = edge;
        boundarys.push_back(boundary);
    }
}
```

## 5. 结果输出

程序会生成三个VTK文件：

- `results/electrothermal_V.vtu`：电势分布
- `results/electrothermal_T.vtu`：温度分布  
- `results/electrothermal_Q.vtu`：焦耳热密度分布

使用ParaView可视化这些文件。

## 6. 与COMSOL验证对比

### 6.1 COMSOL建模步骤

1. **创建几何**
   - 创建单位圆
   - 网格划分（使用相同的网格或导出网格给本程序）

2. **添加物理场**
   - 添加"电流"物理场（EC接口）
   - 添加"传热"物理场（HT接口）
   - 启用多物理场耦合

3. **设置材料参数**
   ```
   电导率: sigma = sigma0 * (1 + alpha * (T - T0))
   热导率: k = 1.0 W/(m·K)
   ```

4. **边界条件**
   - 电场：左半圆 V=1V，右半圆 V=0V
   - 热场：边界对流换热 h=10 W/(m²·K)，T_amb=300K

5. **求解**
   - 使用稳态求解器
   - 启用耦合求解

6. **导出结果**
   - 导出节点温度和电势数据

### 6.2 对比验证

比较以下量：

1. **电势场**
   - 最大值、最小值
   - 沿特定路径的分布

2. **温度场**
   - 最高温度位置和数值
   - 温升分布

3. **焦耳热密度**
   - 最大值位置
   - 分布模式

4. **迭代收敛性**
   - 迭代次数
   - 收敛历史

### 6.3 预期误差

对于此类耦合问题，典型误差来源：

- 网格精度：使用相同网格可消除此误差
- 迭代收敛容差：本程序默认 1e-6
- 积分精度：高斯积分点数（本程序3点）
- 边界条件处理差异

**预期相对误差**：< 1-2%

## 7. 扩展和改进

### 7.1 当前简化

当前实现中的简化：

1. **电导率计算**：使用全局平均温度，实际应在每个积分点插值
2. **焦耳热源**：需要更精确的积分点处理
3. **边界条件**：需要手动修改代码设置

### 7.2 改进方向

1. **更精确的耦合**
   ```cpp
   // 在积分点处计算温度依赖的电导率
   electric_solver_->setCoefficient(
       [this, element_idx, ref_coords](const std::vector<double>&) {
           double T_local = interpolateTemperature(element_idx, ref_coords);
           return computeConductivity(T_local);
       });
   ```

2. **配置文件支持**
   - 通过JSON/XML文件配置边界条件
   - 参数化物理参数

3. **自适应网格**
   - 根据温度梯度自适应加密网格

4. **瞬态分析**
   - 添加时间导数项
   - 时间步进求解

## 9. 注意事项

⚠️ **重要提示**：

1. 电热耦合问题可能存在多解或不收敛，需要合理选择初值和参数
2. 温度系数 `α` 不宜过大，否则可能导致迭代不收敛
3. 边界条件设置不当可能导致无界解
4. 建议先用小网格测试，确认收敛后再用精细网格
