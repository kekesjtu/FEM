# FEM Solver 函数升维分析

本文档分析 `fem_solver.cpp` 中的各个函数在从 2D 升级到 3D 时是否需要修改。

## 函数分类

### ✅ **不需要修改的函数**（已完全通用化）

#### 1. `preprocess()`
**原因：** 已经从 Config 获取维度信息，与具体维度无关。
```cpp
int dimension = config->getDimension();  // 自动获取维度
```
- 矩阵和向量的初始化不依赖于维度
- 节点数和单元数的获取是通用的

#### 2. `assemble()`
**原因：** 完全依赖辅助函数，本身不涉及维度相关操作。
- 使用三元组列表组装，与维度无关
- 调用 `calculateStiffnessEntry()` 和 `calculateLoadEntry()`

#### 3. `applyBoundaryConditions()`
**原因：** 使用统一的工厂模式，自动适配边界单元类型。
```cpp
// 工厂自动根据 Config 中的维度信息创建对应的边界单元
auto mapping = GeometryMappingFactory::createMapping(edge_coords, config, true);
auto shapeFunction = ShapeFunctionFactory::createShapeFunction(config, true);
auto gaussPoint = GaussPointFactory::createGaussPoint(config, true);
```
- 边界条件的施加逻辑（Dirichlet/Neumann/Robin）与维度无关
- 对于 3D，边界是 2D 面（四边形或三角形），Config 会自动处理

#### 4. `solveLinearSystem()`
**原因：** 纯代数求解，与几何维度完全无关。
- 求解器（SparseLU, CG）只看矩阵和向量的大小
- 不涉及任何几何信息

#### 5. `postprocess()`
**原因：** 已经使用工厂模式创建 VTK 输出对象。
```cpp
auto vtkOutput = VTKOutputFactory::createVTKOutput(config, u);
```
- VTK 输出工厂会根据维度自动选择合适的输出格式

#### 6. `calculateBoundaryStiffness()` 和 `calculateBoundaryLoad()`
**原因：** 使用统一工厂模式，完全通用化。
```cpp
int embed_dim = config->getDimension();  // 嵌入空间维度
auto mapping = GeometryMappingFactory::createMapping(edge_coords, config, true);
auto shapeFunction = ShapeFunctionFactory::createShapeFunction(config, true);
```
- 对于 2D：边界是 1D 线段
- 对于 3D：边界是 2D 面（三角形或四边形）
- 工厂会自动创建正确的对象

### ✅ **所有函数已完全通用化**

#### 7. `calculateBoundaryStiffness()` - ✅ 已修复

**修复1：** 动态获取边界节点数
```cpp
int boundary_nodes = config->getBoundaryNodesPerElement();  // ✅ 从 Config 动态获取
if (static_cast<int>(edge_nodes.size()) != boundary_nodes)
{
    throw std::runtime_error("边界节点数不匹配");
}
```

**修复2：** 动态处理参考坐标维度
```cpp
// 边界参考坐标维度 = 体维度 - 1
int boundary_dim = config->getDimension() - 1;

std::vector<double> coord_ref(boundary_dim);
for (int d = 0; d < boundary_dim; ++d) {
    coord_ref[d] = points[gpIndex * boundary_dim + d];
}
```

**维度对应关系：**
- 2D 问题：边界是 1D 线段，参考坐标 `t ∈ [-1,1]`（1个分量）
- 3D 问题：边界是 2D 面，参考坐标 `(ξ,η)` 在三角形或四边形上（2个分量）

#### 8. `calculateBoundaryLoad()` - ✅ 已修复

应用了与 `calculateBoundaryStiffness()` 完全相同的修复。

## 升维所需的准备工作

### 1. 在 Config 中添加 3D 单元类型
```cpp
enum ElementType
{
    LINE,           // 1D（边界）
    TRIANGLE,       // 2D 体单元
    QUADRILATERAL,  // 2D 体单元
    TETRAHEDRON,    // 3D 体单元 ⭐ 需要添加
    HEXAHEDRON      // 3D 体单元 ⭐ 需要添加
};
```

### 2. 实现 3D 单元的形函数
- `TetrahedronLinearShapeFunction`（四面体线性单元）
- `HexahedronLinearShapeFunction`（六面体线性单元）

### 3. 实现 3D 单元的几何映射
- `TetrahedronLinearMapping`
- `HexahedronLinearMapping`

### 4. 实现 3D 单元的高斯积分
- `TetrahedronGauss4Point`（四面体 4 点积分）
- `HexahedronGauss8Point`（六面体 8 点积分）

### 5. 实现 3D 边界单元（2D 面）
对于 3D 问题，边界是 2D 面：
- `getBoundaryElementType()` 应返回 `TRIANGLE` 或 `QUADRILATERAL`
- 已有的 `TriangleLinearShapeFunction` 可直接用作 3D 的边界
- 边界几何映射需要支持嵌入 3D 空间的 2D 面

### 6. 更新 VTK 输出
- 支持 3D 四面体和六面体单元的 VTK 输出

所有高斯点创建现在都从 Config 动态获取参数：

```cpp
// 体单元积分（calculateStiffnessEntry, calculateLoadEntry）
auto gaussPoint = GaussPointFactory::createGaussPoint(
    static_cast<Config::ElementType>(config->getElementType()),
    config->getAssembleGaussPointsNum());

// 边界单元积分（calculateBoundaryStiffness, calculateBoundaryLoad）

    static_cast<Config::ElementType>(config->getBoundaryElementType()),
    config->getBoundaryGaussPointsNum());
```

**结论：整个 `fem_solver.cpp` 现在完全不依赖于具体维度，升级到 3D 无需修改任何代码！**
