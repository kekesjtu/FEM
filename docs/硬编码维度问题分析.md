### 1.1 TriangleLinearMapping 类

#### ❌ 问题1：`computeJacobian()` - 假设嵌入维度为2

**位置**: `geometry_mapping.cpp:119-167`

```cpp
void TriangleLinearMapping::computeJacobian()
{
    // ❌ 硬编码：假设坐标数组格式为 [x0, y0, x1, y1, x2, y2]
    const double x0 = element_coords_[0], y0 = element_coords_[1];
    const double x1 = element_coords_[2], y1 = element_coords_[3];
    const double x2 = element_coords_[4], y2 = element_coords_[5];
    
    // ❌ 硬编码：只计算2D雅可比
    const double dx_dxi = x1 - x0;
    const double dx_deta = x2 - x0;
    const double dy_dxi = y1 - y0;
    const double dy_deta = y2 - y0;
    
    // ❌ 硬编码：2D雅可比行列式
    jacobian_det_ = dx_dxi * dy_deta - dx_deta * dy_dxi;
    
    // ❌ 硬编码：2x2逆雅可比矩阵
    jacobian_inv_.resize(2, std::vector<double>(2));
    jacobian_inv_[0][0] = dy_deta * inv_det;
    jacobian_inv_[0][1] = -dx_deta * inv_det;
    jacobian_inv_[1][0] = -dy_dxi * inv_det;
    jacobian_inv_[1][1] = dx_dxi * inv_det;
}
```

**3D中的问题**：
- 当三角形嵌入在3D空间时（如四面体的边界面），坐标格式应该是 `[x0, y0, z0, x1, y1, z1, x2, y2, z2]`
- 雅可比矩阵应该是 **3×2** 矩阵（不是方阵！）
- 雅可比行列式的计算需要使用叉积而不是2D行列式

void LineLinearMapping::computeJacobian()
{
    // ✅ 动态：使用 embedding_dimension_
    double length_squared = 0.0;
    for (int d = 0; d < embedding_dimension_; ++d)
    {
        double coord0 = element_coords_[d];
        double coord1 = element_coords_[embedding_dimension_ + d];
        double dx = coord1 - coord0;
        length_squared += dx * dx;
    }
}

void LineLinearMapping::mapToPhysical(...) const
{
    // ✅ 动态：使用 embedding_dimension_
    coord_phys.resize(embedding_dimension_);
    
    for (int d = 0; d < embedding_dimension_; ++d)
    {
        coord_phys[d] = N0 * element_coords_[d] + 
                       N1 * element_coords_[embedding_dimension_ + d];
    }
}

## 三、数学背景：非方阵雅可比

### 3.1 嵌入在3D中的三角形

对于嵌入在3D空间中的2D三角形：

**物理坐标映射**：
```
x(ξ,η) = N0(ξ,η)·x0 + N1(ξ,η)·x1 + N2(ξ,η)·x2
y(ξ,η) = N0(ξ,η)·y0 + N1(ξ,η)·y1 + N2(ξ,η)·y2
z(ξ,η) = N0(ξ,η)·z0 + N1(ξ,η)·z1 + N2(ξ,η)·z2
```

**雅可比矩阵** J 是 **3×2** 矩阵：
```
J = [∂x/∂ξ  ∂x/∂η]     [x1-x0  x2-x0]
    [∂y/∂ξ  ∂y/∂η]  =  [y1-y0  y2-y0]
    [∂z/∂ξ  ∂z/∂η]     [z1-z0  z2-z0]
```

**雅可比行列式**（面积元素）：
```
det(J) = ||∂r/∂ξ × ∂r/∂η||

其中：
  ∂r/∂ξ  = (x1-x0, y1-y0, z1-z0)  (切向量1)
  ∂r/∂η  = (x2-x0, y2-y0, z2-z0)  (切向量2)
  
  ∂r/∂ξ × ∂r/∂η = 法向量 (垂直于曲面)
  
  det(J) = ||法向量|| = 曲面的面积元素
```

**梯度变换**：
对于曲面上的标量场 u，梯度在切平面上：
```
∇_surface u = (J^T J)^{-1} J^T ∇_ref u
```

这比2D情况复杂得多！

### 3.2 为什么不能直接用2D公式

**2D平面三角形**：
- J 是 2×2 方阵
- det(J) = 直接计算2阶行列式
- J^{-1} 是 2×2 矩阵

**3D曲面三角形**：
- J 是 3×2 矩形矩阵（不可逆！）
- det(J) 需要用叉积计算
- 梯度变换需要广义逆

## 四、解决方案

### 方案A：条件编译（推荐）⭐

根据 `embedding_dimension_` 动态选择计算方法：

```cpp
void TriangleLinearMapping::computeJacobian()
{
    if (embedding_dimension_ == 2)
    {
        // 2D平面三角形：使用现有代码
        compute2DJacobian();
    }
    else if (embedding_dimension_ == 3)
    {
        // 3D曲面三角形：使用叉积
        compute3DSurfaceJacobian();
    }
    else
    {
        throw std::runtime_error("Unsupported embedding dimension");
    }
}

private:
void compute2DJacobian()
{
    // 现有的2D代码
    const double x0 = element_coords_[0], y0 = element_coords_[1];
    const double x1 = element_coords_[2], y1 = element_coords_[3];
    const double x2 = element_coords_[4], y2 = element_coords_[5];
    
    const double dx_dxi = x1 - x0;
    const double dx_deta = x2 - x0;
    const double dy_dxi = y1 - y0;
    const double dy_deta = y2 - y0;
    
    jacobian_det_ = dx_dxi * dy_deta - dx_deta * dy_dxi;
    
    // ... 2x2逆矩阵计算
}

void compute3DSurfaceJacobian()
{
    // 3D曲面：使用叉积
    // 坐标格式: [x0,y0,z0, x1,y1,z1, x2,y2,z2]
    
    // 两个切向量
    double t1[3] = {
        element_coords_[3] - element_coords_[0],  // x1 - x0
        element_coords_[4] - element_coords_[1],  // y1 - y0
        element_coords_[5] - element_coords_[2]   // z1 - z0
    };
    
    double t2[3] = {
        element_coords_[6] - element_coords_[0],  // x2 - x0
        element_coords_[7] - element_coords_[1],  // y2 - y0
        element_coords_[8] - element_coords_[2]   // z2 - z0
    };
    
    // 法向量 = t1 × t2
    double normal[3] = {
        t1[1]*t2[2] - t1[2]*t2[1],
        t1[2]*t2[0] - t1[0]*t2[2],
        t1[0]*t2[1] - t1[1]*t2[0]
    };
    
    // 雅可比行列式 = ||法向量||
    jacobian_det_ = std::sqrt(
        normal[0]*normal[0] + 
        normal[1]*normal[1] + 
        normal[2]*normal[2]
    );
    
    // ⚠️ 注意：3D情况下的"逆雅可比"更复杂
    // 需要计算 (J^T J)^{-1} J^T
    computeSurfaceGradientTransform(t1, t2);
}

void computeSurfaceGradientTransform(const double t1[3], const double t2[3])
{
    // 计算度量张量 G = J^T J (2×2矩阵)
    double g11 = t1[0]*t1[0] + t1[1]*t1[1] + t1[2]*t1[2];  // t1·t1
    double g12 = t1[0]*t2[0] + t1[1]*t2[1] + t1[2]*t2[2];  // t1·t2
    double g22 = t2[0]*t2[0] + t2[1]*t2[1] + t2[2]*t2[2];  // t2·t2
    
    // G^{-1} (2×2矩阵)
    double det_g = g11*g22 - g12*g12;
    double g_inv_11 = g22 / det_g;
    double g_inv_12 = -g12 / det_g;
    double g_inv_22 = g11 / det_g;
    
    // 存储梯度变换矩阵：G^{-1} J^T (2×3矩阵)
    // gradient_transform_[i][j] 表示从参考坐标i到物理坐标j的变换
    gradient_transform_.resize(2, std::vector<double>(3));
    
    for (int j = 0; j < 3; ++j)  // 物理坐标方向
    {
        gradient_transform_[0][j] = g_inv_11 * t1[j] + g_inv_12 * t2[j];
        gradient_transform_[1][j] = g_inv_12 * t1[j] + g_inv_22 * t2[j];
    }
}
```
