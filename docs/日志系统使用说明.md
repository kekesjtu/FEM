# 日志系统使用说明

## 概述

项目已经实现了统一的日志输出系统，支持分级控制输出详细程度。

## 日志级别

系统支持5个日志级别（从低到高）：

| 级别        | 说明         | 使用场景               |
| ----------- | ------------ | ---------------------- |
| **DEBUG**   | 详细调试信息 | 开发调试、问题诊断     |
| **INFO**    | 一般信息     | 正常运行时的关键信息   |
| **WARNING** | 警告信息     | 潜在问题，程序仍可继续 |
| **ERROR**   | 错误信息     | 严重错误，影响功能     |
| **NONE**    | 不输出日志   | 生产环境完全静默       |

## 使用方法

### 1. 在代码中设置日志级别

在`src/main.cpp`的`main`函数开始处：
```cpp
// 设置为INFO级别（简洁输出）
Logger::getInstance().setLogLevel(LogLevel::INFO);

// 或设置为DEBUG级别（详细输出）
Logger::getInstance().setLogLevel(LogLevel::DEBUG);

// 或设置为WARNING级别（只显示警告和错误）
Logger::getInstance().setLogLevel(LogLevel::WARNING);
```

### 2. 启用文件输出（可选）

```cpp
// 同时输出到文件
Logger::getInstance().enableFileOutput("fem_solver.log");
```

### 3. 在代码中使用日志

```cpp
#include "logger.h"

// 调试信息（只在DEBUG级别显示）
LOG_DEBUG("详细的调试信息");

// 一般信息（INFO及以上级别显示）
LOG_INFO("程序运行状态");

// 警告信息
LOG_WARNING("潜在问题");

// 错误信息
LOG_ERROR("严重错误");

// 标题分隔线
LOG_HEADER("主要章节标题");
LOG_SUBHEADER("次级标题");
```

## 日志分级原则

项目中的日志分级遵循以下原则：

### DEBUG级别输出
- 每次迭代的详细过程
- 矩阵组装的三元组数量
- 边界条件的详细统计
- 网格解析的每个步骤
- 单元类型识别过程
- 积分点计算详情

### INFO级别输出
- 程序启动和结束
- 主要求解阶段（组装、求解、后处理）
- 网格统计信息（节点数、单元数）
- 迭代收敛信息
- 求解耗时
- 结果文件输出

### WARNING级别输出
- 未找到可选配置项
- 使用默认值
- 达到最大迭代次数但未完全收敛

### ERROR级别输出
- 文件读取失败
- 网格解析错误
- 矩阵求解失败
- 必需配置缺失

## 性能影响

- **INFO级别**：几乎无性能影响，推荐日常使用
- **DEBUG级别**：会产生大量输出，可能影响大规模问题的性能
- **WARNING级别**：最小输出，适合批量计算

## 未来改进

计划在JSON配置文件中添加日志级别配置：
```json
{
  "log_level": "INFO",
  "log_file": "output.log"
}
```

这样可以在不修改代码的情况下调整日志输出。
