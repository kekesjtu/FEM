# FEM项目测试指南

## 快速测试流程

### 方法1: 使用CMake编译并运行单个测试

```powershell
# 1. 编译特定测试程序
cmake --build build --target test_3d_mesh_import

# 2. 运行测试
.\build\bin\test_3d_mesh_import.exe
```

### 方法2: 编译并运行所有测试

```powershell
# 1. 确保BUILD_TESTS已启用 (在CMakeLists.txt中已设为ON)
cmake -B build -S . -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Debug -DBUILD_TESTS=ON

# 2. 编译所有测试
cmake --build build

# 3. 运行所有测试 (使用CTest)
cd build
ctest --output-on-failure

# 或者手动运行每个测试
cd ..
.\build\bin\test_3d_mesh_import.exe
```

### 方法3: 一键编译并运行 (推荐)

```powershell
# 编译并立即运行
cmake --build build --target test_3d_mesh_import ; .\build\bin\test_3d_mesh_import.exe
```

## 创建新测试

### 1. 在tests/目录下创建新的.cpp文件

```cpp
// tests/test_my_feature.cpp
#include <iostream>
#include "../include/my_header.h"

int main()
{
    std::cout << "测试开始..." << std::endl;
    
    // 你的测试代码
    bool test_passed = true;
    
    // ... 测试逻辑 ...
    
    if (test_passed)
    {
        std::cout << "✓ 测试通过!" << std::endl;
        return 0;
    }
    else
    {
        std::cerr << "✗ 测试失败!" << std::endl;
        return 1;
    }
}
```

### 2. tests/CMakeLists.txt会自动发现新测试

当前配置使用`file(GLOB TEST_SOURCES "*.cpp")`自动发现所有测试文件,无需手动添加。

### 3. 重新配置并编译

```powershell
cmake -B build -S . -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Debug
cmake --build build --target test_my_feature
.\build\bin\test_my_feature.exe
```

## 当前可用测试

### test_3d_mesh_import
测试3D四面体网格导入功能

**测试内容:**
- ✓ 识别3D空间维度
- ✓ 解析3D节点坐标
- ✓ 识别四面体单元(tet, 4节点)
- ✓ 识别三角形边界单元(tri作为边界)
- ✓ 忽略低维单元(edg在3D中, vtx)
- ✓ 数据一致性验证

**运行方法:**
```powershell
cmake --build build --target test_3d_mesh_import
.\build\bin\test_3d_mesh_import.exe
```

**预期输出:**
```
================================================
     3D四面体网格导入测试
================================================
...
✓✓✓ 所有测试通过! ✓✓✓
3D四面体网格导入功能正常
================================================
```

## 测试网格文件

测试程序使用以下网格文件:
- `cube_tet_mesh.mphtxt` - 3D四面体网格 (从`正方体域四面体网格.mphtxt`复制,避免中文路径问题)
- `circle_mesh3.mphtxt` - 2D三角形网格

**注意事项:**
- 测试程序从项目根目录运行
- 避免在网格文件名中使用中文,可能导致编码问题
- 网格文件应放在项目根目录

## 调试测试

如果测试失败,可以:

1. **查看详细输出:**
```powershell
.\build\bin\test_3d_mesh_import.exe
```

2. **使用调试器:**
在VS Code中:
- 打开测试文件
- 设置断点
- 按F5启动调试
- 在launch.json中配置测试程序路径

3. **检查编译错误:**
```powershell
cmake --build build --target test_3d_mesh_import
```

## 测试最佳实践

### ✓ 应该做的:
- 每个测试一个独立的.cpp文件
- 测试文件名以`test_`开头
- 返回0表示成功,非0表示失败
- 使用清晰的输出信息 (✓/✗ 标记)
- 测试多个方面 (维度检查、数据一致性等)

### ✗ 不应该做的:
- 在测试中修改源代码
- 依赖于执行顺序
- 使用绝对路径(除非必要)
- 中文文件名(可能有编码问题)

## VS Code集成

可以创建tasks.json任务来快速运行测试:

```json
{
    "label": "Run 3D Mesh Import Test",
    "type": "shell",
    "command": "cmake --build ${workspaceFolder}/build --target test_3d_mesh_import && ${workspaceFolder}/build/bin/test_3d_mesh_import.exe",
    "group": "test",
    "problemMatcher": []
}
```

然后使用 `Ctrl+Shift+P` → `Tasks: Run Task` → 选择测试任务

## 持续集成 (CI)

如果要设置CI,可以在`.github/workflows/test.yml`中添加:

```yaml
name: Tests

on: [push, pull_request]

jobs:
  test:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v2
      - name: Configure CMake
        run: cmake -B build -DBUILD_TESTS=ON
      - name: Build
        run: cmake --build build
      - name: Run tests
        run: cd build && ctest --output-on-failure
```

## 故障排查

### 问题: "无法打开文件"
**解决方案:** 
- 检查文件路径是否正确
- 使用英文文件名
- 确保从正确的目录运行

### 问题: 链接错误
**解决方案:**
```powershell
# 重新编译FEM_lib
cmake --build build --target FEM_lib
# 再编译测试
cmake --build build --target test_3d_mesh_import
```

### 问题: 测试未被发现
**解决方案:**
```powershell
# 重新配置CMake
cmake -B build -S . -DBUILD_TESTS=ON
cmake --build build
```
