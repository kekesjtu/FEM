## 测试2: 线性响应验证

### 问题设置
单位立方体 [0,1]³，所有边界 u=0

**案例A**: -∇²u = 1
**案例B**: -∇²u = 10

### 网格信息
- 节点数: 6033
- 四面体单元数: 32439
- 边界三角形数: 2412

### 数值结果

| 源项 f | 最大解值 u_max | 比例 |
| ------ | -------------- | ---- |
| 1.0    | 0.0561         | 1×   |
| 10.0   | 0.5612         | 10×  |

**比例关系**: u_max(f=10) / u_max(f=1) = 10.00

### 结论
**求解器满足线性叠加原理 ✓**

线性泊松方程的解应满足: 如果 f₂ = k·f₁，则 u₂ = k·u₁

实测比例 = 10.00 / 1.00 = **10.0** (精确)

## 测试3: 解的数量级估计

### 理论估计
对于 -∇²u = 1 在单位立方体 [0,1]³ 上，边界 u=0

使用维度分析:
- 特征长度尺度: L = 1
- 泊松方程: ∇²u ~ f
- 因此: u ~ f·L² = 1·1² = 1

但考虑到边界条件的约束，中心点解值应该小于这个估计。

**粗略估计**: u_center ~ 0.01 - 0.1

**实测值**: u_max = 0.056 ✓ (在合理范围内)

## 与COMSOL对比的问题

### 观察
用户报告ParaView显示结果与COMSOL完全不同

### 可能原因

1. **参数设置不同**
   - COMSOL中的 ρ/ε 值可能不是10
   - COMSOL可能使用了不同的单位系统

2. **边界条件不同**
   - COMSOL可能不是所有边界都接地
   - 可能有部分边界是Neumann或Robin条件

3. **坐标单位问题**
   - 网格可能不是米制单位
   - 可能需要单位转换

4. **场的定义不同**
   - COMSOL可能计算的是电场强度而非电势
   - 可能有额外的缩放因子

### 建议验证步骤

1. 检查COMSOL中的实际参数设置
2. 导出COMSOL的数值解并与我们的结果对比
3. 确认两边使用相同的物理量和单位
4. 比较边界条件的具体设置
