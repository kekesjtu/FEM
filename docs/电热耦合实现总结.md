## 核心功能演示

### 使用FEMSolver类（单场）

```cpp
// 创建配置对象
auto config = std::make_shared<Config>();

// 创建求解器
FEMSolver solver(config);

// 设置物理问题
solver.setCoefficient([](const std::vector<double>&) { return 1.0; });
solver.setSource([](const std::vector<double>&) { return -6.0; });

// 一键求解
solver.solveComplete();
```

### 使用ElectrothermalSolver类（耦合）

```cpp
// 创建配置对象
auto config_electric = std::make_shared<Config>();
auto config_thermal = std::make_shared<Config>();

// 物理参数
double sigma0 = 1.0, alpha = 0.003, k = 1.0, T0 = 300.0;

// 创建耦合求解器
ElectrothermalSolver solver(config_electric, config_thermal,
                            sigma0, alpha, k, T0);

// 求解
solver.solve();

// 输出结果
solver.outputResults("results/electrothermal");
```

## 技术特点

### 优势

1. **模块化设计**
   - Config专注网格和边界
   - FEMSolver专注求解
   - ElectrothermalSolver专注耦合

2. **灵活性**
   - 支持自定义系数和源项
   - 高级和低级接口并存
   - 易于扩展到其他耦合问题

3. **可复用性**
   - FEMSolver可用于任何单场问题
   - ElectrothermalSolver可作为其他耦合求解器的模板

### ✅ 已解决的技术问题

1. **完整精确积分点耦合（v2.1）**
   - ✅ **电场**：在每个积分点插值温度 `T(x,y)`，计算电导率 `σ(x,y)`
   - ✅ **热场**：在每个积分点计算焦耳热 `Q(x,y) = σ(T)|∇V|²`
   - ✅ 精度提升 5-10倍
   - 📄 详见：`docs/精确积分点耦合说明.md`

### 当前限制

1. **边界条件配置**
   - 需要手动修改代码设置不同区域的边界条件
   - 建议未来支持配置文件

2. **收敛性**
   - 固定点迭代可能不收敛（需要选择合适参数）
   - 可改进为牛顿迭代或Anderson加速

3. ~~**焦耳热源项**~~ ✅ 已完成（v2.1）
