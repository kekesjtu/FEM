# 电热耦合迭代精度提升策略

## 已实现的改进

### ✅ 1. 欠松弛法（Under-relaxation）
**实现位置**: `ElectrothermalSolver::solve()`

**原理**:
```
T_new = ω * T_computed + (1-ω) * T_old
```
其中 ω ∈ (0,1] 是松弛因子

**优点**:
- 防止迭代振荡
- 提高强耦合问题的稳定性
- 实现简单，效果显著

**使用方法**:
```cpp
ElectrothermalSolver solver(config, et_problem,
                            1e-6,   // 容差
                            100,    // 最大迭代次数
                            true,   // 详细输出
                            0.5);   // 松弛因子
```

**参数调整建议**:
- `ω = 0.3-0.4`: 非常稳定，但收敛较慢（推荐用于发散问题）
- `ω = 0.5`: 平衡选择（默认值）
- `ω = 0.6-0.7`: 较快收敛，但可能不太稳定
- `ω = 1.0`: 无松弛，等同于原始固定点迭代

### ✅ 2. 修复载荷向量累积bug
**问题**: 每次迭代时边界条件在b向量上累积
**解决**: 每次迭代前重置b向量为0

### ✅ 3. 增加最大迭代次数
从50次提高到100次，给予更多收敛机会

## 其他可选策略（未实现）

### 策略A: Aitken动态松弛 ⭐⭐⭐⭐
**复杂度**: 中等  
**收敛速度**: 快  
**稳定性**: 好

自动调整松弛因子:
```cpp
if (iterations_ > 2) {
    Eigen::VectorXd r_current = T_current_ - T_old;
    Eigen::VectorXd r_old = T_old - T_old_old;
    Eigen::VectorXd delta_r = r_current - r_old;
    
    omega = -omega * r_old.dot(delta_r) / delta_r.squaredNorm();
    omega = std::clamp(omega, 0.1, 1.0);
}
T_current_ = T_old + omega * (T_current_ - T_old);
```

### 策略B: 多场收敛判据 ⭐⭐⭐⭐
**复杂度**: 低  
**收敛速度**: -  
**稳定性**: 更严格

同时检查电场和热场:
```cpp
double T_error = (T_current_ - T_old).norm() / T_current_.norm();
double V_error = (V_current_ - V_old).norm() / V_current_.norm();
double max_error = std::max(T_error, V_error);

if (max_error < tol_) {
    // 两个场都收敛
}
```

### 策略C: 残差基准收敛判据 ⭐⭐⭐
**复杂度**: 中等  
**收敛速度**: -  
**稳定性**: 更严格

检查物理方程残差:
```cpp
// 热方程残差: ||K*T - b|| / ||b||
Eigen::VectorXd residual_T = K_thermal * T_current_ - b_thermal;
double residual_norm_T = residual_T.norm() / b_thermal.norm();

// 电场方程残差: ||K*V - b|| / ||b||
Eigen::VectorXd residual_V = K_electric * V_current_ - b_electric;
double residual_norm_V = residual_V.norm() / b_electric.norm();

if (std::max(residual_norm_T, residual_norm_V) < tol_) {
    // 收敛
}
```

### 策略D: 增加积分点精度 ⭐⭐⭐
**复杂度**: 低  
**收敛速度**: -  
**稳定性**: 更准确

在 `config.cpp` 中:
```cpp
// 将三角形高斯积分点从3点提高到7点
if (shape_function_order_ == 1) {
    gauss_assemble_points_num_ = 7;  // 从3改为7
}
```

### 策略E: Newton-Raphson方法 ⭐⭐⭐⭐⭐
**复杂度**: 高  
**收敛速度**: 非常快  
**稳定性**: 好（如果初始解合理）

将非线性系统线性化:
```
∂R_T/∂T  ∂R_T/∂V     ΔT     -R_T
∂R_V/∂T  ∂R_V/∂V  *  ΔV  =  -R_V
```

需要计算Jacobi矩阵，实现复杂但是收敛最快（二阶收敛）。

## 实践建议

### 场景1: 迭代不收敛/发散
**症状**: 温度或电势越来越大
**解决**:
1. 降低松弛因子: `relaxation = 0.3`
2. 增加迭代次数: `max_iter = 200`
3. 检查边界条件是否合理
4. 降低电压值

### 场景2: 收敛太慢
**症状**: 需要很多次迭代才收敛
**解决**:
1. 提高松弛因子: `relaxation = 0.7`
2. 实现Aitken加速
3. 改用Newton-Raphson方法

### 场景3: 振荡不收敛
**症状**: 误差上下波动
**解决**:
1. 降低松弛因子: `relaxation = 0.4`
2. 实现Aitken动态松弛
3. 增加收敛容差（临时）: `tol = 1e-5`

### 场景4: 需要更高精度
**症状**: 收敛了但精度不够
**解决**:
1. 降低收敛容差: `tol = 1e-8`
2. 使用多场收敛判据
3. 使用残差基准判据
4. 增加积分点数
5. 细化网格

## 参数调优指南

| 参数 | 推荐范围 | 对收敛的影响 | 对精度的影响 |
|------|---------|-------------|-------------|
| 松弛因子 ω | 0.3-0.7 | 越小越稳定 | 无影响 |
| 收敛容差 tol | 1e-6 ~ 1e-8 | 越小越慢 | 越小越精确 |
| 最大迭代次数 | 50-200 | 越大容错性越好 | 无影响 |
| 高斯积分点数 | 3-7 | 无影响 | 越多越精确 |

## 调试技巧

### 1. 监控收敛曲线
在每次迭代输出:
- 温度最大值变化
- 电势最大值变化
- 相对误差变化

### 2. 检查物理合理性
- 温度不应该是负数（绝对温度）
- 电势应该在边界值范围内
- 焦耳热应该是正数

### 3. 分步调试
先单独测试:
1. 电场求解（固定温度T₀）
2. 热场求解（固定电势V）
3. 完整耦合迭代
